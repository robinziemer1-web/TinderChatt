

# TinderChatt – Konsolchatt

Det här är ett enkelt chattprogram som körs i konsolen. Du ansluter till en server, 
väljer ett namn och kan sedan skriva meddelanden i realtid tillsammans med andra som är uppkopplade.

## Starta programmet

När programmet startar får du ange ett användarnamn.  
Namnet måste vara ifyllt, annars får du skriva in det igen.

Efter det kopplar programmet upp dig mot chatten automatiskt.

## Skriva och skicka meddelanden

Längst ner i fönstret finns inmatningsraden:

Här skriver du ditt meddelande och trycker **Enter** för att skicka.

Meddelanden som du skickar och tar emot visas i chatten med:

- namn  
- tidsstämpel  
- själva texten  

## Systemhändelser

Programmet visar också systemmeddelanden i gult, till exempel:

- när någon ansluter  
- när någon lämnar chatten  

Det gör det lätt att se vad som händer i rummet.

## Avsluta chatten (/quit)

Om du vill logga ut och stänga programmet skriver du /quit.

När du skriver /quit

- du kopplas bort från servern  
- andra får ett systemmeddelande att du lämnat  
- programmet avslutas direkt

## Sammanfattning

- Ange ett användarnamn  
- Skicka meddelanden i realtid  
- Se andra användares meddelanden  
- Se systemhändelser (join/leave)  
- Avsluta programmet med `/quit`.
